# 本地数据处理与分析标准操作流程（SOP）

## 1. 核心铁律：代码执行驱动，禁止心算与手抄

1. 涉及计数、分组聚合、同比/环比、金额与日期计算、去重与异常值清洗时，**必须编写并执行 Python 脚本**（默认在 Docker 沙箱内运行），绝不用自然语言心算或人工抄写大表格。
2. 原始输入数据视为只读证据，清洗产物一律输出到独立输出路径或工作目录，严禁直接覆盖原始文件。

## 2. 编码、金额与日期硬规则

1. **中文 CSV 导出**：供 Excel 打开的中文 CSV 默认使用 **`utf-8-sig`（UTF-8-BOM）** 编码，避免 Windows Excel 打开乱码。
2. **金额与数值精度**：涉及财务/金额计算时使用 `Decimal` 或明确四舍五入规则，输出默认保留两位小数，严禁浮点尾数直接展示。
3. **日期标准化**：统一解析并标准化为 ISO `YYYY-MM-DD`（或 `YYYY-MM-DD HH:MM:SS`），显式记录无法解析的异常行号而非静默丢弃。

## 3. 验证驱动完成（强制断言清单）

脚本写完不等于完成，必须在脚本末尾或独立校验步骤运行确定性断言并打印核对摘要：
- 输入行数 vs 输出行数、去重/过滤行数守恒核对；
- 关键列空值率、唯一键冲突、数值范围与合计金额勾稽校验；
- 目标产物文件存在、编码正确、可被重新读取解析。

## 4. 默认交付形态：单文件交互式 HTML 报告

对于复杂数据分析与调研汇报，除保留清洗后的数据文件与简要 Markdown 摘要外，**默认交付一个本地浏览器可直接双击打开的单文件交互式 HTML 报告**：
1. 所有统计指标、明细表格与图表数据必须由 Python 脚本直接序列化为 JSON 注入 HTML，**彻底绕过 LLM 抄数**；
2. HTML 必须完全自包含（内联 CSS/JS 与轻量原生 Canvas/SVG 或内联图表逻辑，不依赖断网环境下失效的外部 CDN）；
3. 至少包含：核心 KPI 概览卡片、可视化图表、支持关键字搜索与列排序的交互式明细表、数据口径与清洗核对说明。
